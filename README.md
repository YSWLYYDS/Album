# Album

一个基于 **Qt Widgets** 开发的桌面相册管理与幻灯片播放应用。用户可以创建或打开相册项目，异步扫描或导入图片，在树形目录中浏览图片，并以大图或全屏轮播方式查看。

## 功能

- 创建本地相册项目，或打开已有图片目录。
- 在项目树中递归展示文件夹和图片。
- 异步扫描与导入，避免大量图片操作阻塞界面；支持取消任务。
- 将文件夹中的图片导入指定项目，并保留目录结构。
- 双击树中的图片，在主视图中等比例显示。
- 通过上一张、下一张按钮切换当前图片，窗口尺寸变化时自动重新缩放。
- 全屏无边框轮播视图，提供播放/暂停、前后切换和缩略图预览。
- 使用 LRU 缩略图缓存与后台缩略图任务，改善轮播预览性能。
- 支持选择 MP3 背景音乐；轮播时也会从 `music/` 目录查找并循环播放 MP3、FLAC 或 WAV 文件。

## 技术栈

- C++17
- Qt Widgets、Core、Gui、Multimedia
- Qt Designer `.ui` 界面文件
- Qt Resource System（图标与 QSS 样式）

## 环境要求

- Qt 6（项目使用 `QMediaPlayer` / `QAudioOutput` 的 Qt 6 接口）
- 支持 C++17 的编译器
- Qt Creator 或 `qmake`

## 构建与运行

### Qt Creator

1. 使用 Qt Creator 打开 [Album.pro](Album.pro)。
2. 选择已安装的 Qt 6 Desktop Kit。
3. 构建并运行项目。

### 命令行

在项目根目录执行：

```powershell
qmake Album.pro
make
```

Windows 上若使用 MinGW，`make` 通常为 `mingw32-make`；若使用 MSVC，则使用对应的 `nmake` 或直接通过 Qt Creator 构建。

## 使用说明

1. 启动程序后，选择菜单栏的“文件 → 创建项目”（`Ctrl+N`），填写项目名称和保存位置。
2. 在左侧项目节点上右键，选择“导入文件”，选择包含图片的目录。
3. 也可选择“文件 → 打开”（`Ctrl+O`），直接扫描已有目录。
4. 双击树中的图片可在右侧查看；鼠标移入图片区域后可使用前后按钮切换。
5. 在项目节点的右键菜单中选择“轮播图播放”，打开全屏幻灯片。
6. 通过“设置 → 背景音乐”（`Ctrl+M`）选择 MP3 文件；也可以在项目、工作目录或可执行文件上层目录的 `music/` 文件夹中放入音频文件。

## 项目结构

```text
Album/
├── Album.pro              # qmake 项目配置
├── main.cpp               # 程序入口、QSS 加载与元类型注册
├── mainwindow.*           # 主窗口、菜单与主视图布局
├── protree*               # 项目树、目录与图片节点管理
├── importworker.*         # 后台导入任务
├── scanworker.*           # 后台目录扫描任务
├── picshow.*              # 大图预览与前后切换
├── slideshowdlg.*         # 全屏轮播窗口
├── picanimationwid.*      # 轮播动画逻辑
├── prelist*               # 轮播缩略图列表
├── thumbcache.*           # LRU 缩略图缓存
├── thumbnailtask.*        # 后台缩略图生成任务
├── music/                 # 可选的背景音乐目录
├── icon/                  # 图标资源
└── style/                 # QSS 样式资源
```

## 图片与音频说明

- 示例图片位于 [`album/`](album/)；它们可用于快速验证导入、树形浏览和轮播功能。
- 背景音乐可从界面中手动选择 MP3，也可放在项目根目录或程序可搜索到的 `music/` 目录中。
- 图片扫描和导入均在后台线程处理，但树形界面的更新会回到主线程执行。
