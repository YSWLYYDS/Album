# 营销素材归档与审核工具

基于 **Qt 6 / C++17 / SQLite** 开发的 Windows 桌面端素材管理工具，面向营销图片从导入、预检、审核到结果导出的完整流程。项目同时保留相册式资源浏览与幻灯片预览能力，适合作为 Qt Widgets、异步任务和本地数据持久化的综合实践项目。

## 项目亮点

- 将“目录扫描—图片预检—人工审核—结果导出”整合为一个桌面工作台。
- 大批量图片的扫描、导入和缩略图生成均在后台执行，避免阻塞主界面。
- 使用 SQLite 保存批次、素材状态和修改历史，关闭程序后仍可继续审核。
- 使用 LRU 缩略图缓存减少重复解码，提升列表切换和图片预览速度。
- 保存审核结果前校验源文件大小与修改时间，避免素材被替换后继续审核错版文件。
- 使用版本号进行乐观并发控制；记录已被修改时拒绝覆盖并提示刷新。
- CSV 导出采用安全转义并防止公式注入，可直接交付后续统计或归档。

## 功能模块

### 素材审核工作台

- 按“投放项目 / 渠道 / 素材批次”建立归档批次。
- 支持导入目录、选择多张图片以及向当前批次追加图片。
- 递归扫描 `PNG`、`JPG/JPEG`、`BMP`、`WebP`，预检图片可读性并采集尺寸、格式、文件大小和修改时间。
- 支持取消扫描、分批写入数据库、查看导入异常记录。
- 按审核状态和关键词筛选；关键词覆盖文件名、标签、退回原因和备注。
- 支持待审核、通过、退回三种状态；退回时必须填写原因。
- 支持审核人、素材标签、备注、快捷退回原因和“保存后继续下一张”。
- 支持最多 100 条素材的批量审核。
- 保存每次修改前后的完整快照，可查看单张素材的审核历史。
- 展示批次总数、待审核、已通过和已退回数量。
- 按当前筛选条件导出全部审核记录为 UTF-8 CSV。

### 图片资源浏览

- 创建相册项目，或直接打开已有图片目录。
- 在树形目录中递归展示文件夹与图片。
- 后台扫描、导入并保留原有目录结构，任务支持取消。
- 大图等比例预览，支持前后切换和窗口尺寸自适应。
- 全屏无边框幻灯片，支持播放、暂停、前后切换和缩略图列表。
- 后台生成缩略图并通过 LRU 缓存复用结果。

## 数据与并发设计

本地数据库包含三类核心数据：

| 表 | 用途 |
| --- | --- |
| `review_batches` | 保存投放项目、渠道、批次编号与素材根目录 |
| `review_images` | 保存图片元数据、审核状态、标签、备注和版本号 |
| `review_events` | 保存每次审核修改前后的快照及操作时间 |

图片扫描在线程中进行，每累计一批结果便通过信号返回主线程，由主线程完成 SQLite 写入和界面刷新。图片预览与缩略图生成交给全局线程池处理，界面控件只在 GUI 线程更新。

默认数据库位于 Qt 的应用本地数据目录，文件名为 `image-review.db`。需要指定数据库位置时，可设置环境变量：

```powershell
$env:IMAGE_REVIEW_DATABASE = "D:\data\image-review.db"
```

## 构建环境

- Qt 6.x Desktop Kit
- 支持 C++17 的 MinGW 或 MSVC 编译器
- Qt Creator，或可用的 `qmake` 命令行环境

## 构建与运行

### Qt Creator

1. 使用 Qt Creator 打开 `Album.pro`。
2. 选择 Qt 6 Desktop Kit。
3. 执行“构建并运行”。

### 命令行（MinGW）

```powershell
qmake Album.pro
mingw32-make -j
```

如使用 MSVC，请在相应的开发者命令行中使用 `nmake`。

## 快速体验

1. 启动程序，进入“营销素材归档与审核”页。
2. 点击“导入素材”，选择“新批次：导入目录”。
3. 填写投放项目、渠道和批次编号，并选择 `营销素材演示包`。
4. 在左侧选择图片，在右侧填写审核人、状态、标签或退回原因。
5. 点击“保存审核”，或勾选多行执行批量审核。
6. 通过状态和关键词筛选记录，并导出 CSV 结果。

也可进入“图片资源浏览”页，打开图片目录后体验树形浏览、大图预览和幻灯片播放。

## 项目结构

```text
Album/
├─ Album.pro                 # qmake 项目配置
├─ main.cpp                  # 程序入口、字体与 QSS 初始化
├─ mainwindow.*              # 主窗口与双工作区入口
├─ reviewworkspace.*         # 素材导入、筛选、审核和导出界面
├─ reviewrepository.*        # SQLite 仓储、事务与审核历史
├─ reviewscanworker.h        # 后台素材扫描和图片预检
├─ imageprobe.h              # 图片格式及元数据校验
├─ fitimageview.h            # 审核页缩放/平移预览
├─ protree*                  # 相册项目树与目录管理
├─ importworker.*            # 后台图片导入
├─ scanworker.*              # 后台目录扫描
├─ picshow.*                 # 大图预览与前后切换
├─ slideshowdlg.*            # 全屏幻灯片
├─ thumbcache.*              # LRU 缩略图缓存
├─ thumbnailtask.*           # 后台缩略图任务
├─ 营销素材演示包/           # 可直接导入的演示图片
├─ icon/                     # 图标资源
└─ style/                    # QSS 样式
```

## 边界说明

- 审核人名称仅记录在本机数据库中，不等同于账号身份认证。
- 本工具保存的是内部素材审核结果，不代表第三方广告平台的审核结论。
- 当前版本面向本地单机工作流；多人协作需要接入服务端身份与权限体系。
